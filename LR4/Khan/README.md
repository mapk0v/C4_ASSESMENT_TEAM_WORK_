## Как открыть исходники PlantUML

1. Откройте каталог проекта в VS Code с расширением PlantUML.
2. Убедитесь, что рендерер имеет доступ к стандартной C4-PlantUML через `!include https://raw.githubusercontent.com/...`.
3. Откройте файл и выберите PlantUML Preview / Export PNG или SVG.
4. Выполните `python validate.py` для дополнительной проверки ID и нумерации.

Сети и конфигурации серверов здесь **проектные**, а не скриншот уже работающего развёртывания. Реальные настройки согласуются с командой.

Перед сдачей впишите своё ФИО на титульный лист DOCX и проверьте название кафедры, профиль и ФИО преподавателя по требованиям вашей группы. После правок в Word пересохраните PDF.

## Согласование с предыдущими лабораторными

- `analytics_service` — один и тот же контейнер L2/L3 и узел в Deployment.
- `grpc_handler`, `analytics_coordinator`, `rating_calc`, `analytics_repo` — ID компонентов именно из L3 Analytics.
- `api_gateway`, `notification_service`, `database` — ID общих контейнеров.
- `rating_calc` получает список оценок через координатор и вычисляет **только выбранный модуль**. Алгоритмы среднего, медианы и минимума — альтернативные **учебные аналитические показатели** из ЛР3.
- Дополнительный внешний `finance_scholarship` показан в L0 **как планируемое расширение, не как готовая активная связь**. До утверждения этой интеграции L1–L3 не меняются.
