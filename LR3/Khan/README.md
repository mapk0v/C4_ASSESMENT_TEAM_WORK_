## Зафиксированные правила предметной области

- Оценка **по каждой дисциплине** — целое число от 0 до 54 баллов.
- 45–54 — отлично, 35–44 — хорошо, 25–34 — удовлетворительно, 0–24 — не сдал.
- Первый и второй модули оцениваются **независимо** по тем же дисциплинам.
- Оценка по дисциплине в первом модуле не суммируется и не усредняется с оценкой во втором.
- Полная запись оценки однозначно определяется студентом, дисциплиной, учебным годом и номером модуля.
- Если оценки по дисциплине пока нет, прототип её **не выдумывает** и не считает нулём.

**Предположение прототипа:** по каждой дисциплине за конкретный модуль фиксируется одна итоговая оценка (если будут пересдачи — требуется расширение модели). Термины «не сдал» и «несданный результат» используются здесь без утверждения официального статуса академической задолженности.

## Что является учебным допущением

В предоставленных материалах нет нормативной формулы **единого рейтинга по нескольким дисциплинам**. Поэтому три Strategy — это **три альтернативных аналитических показателя**: среднее арифметическое, медиана и минимальная оценка. **Ни один из них не считается официальной итоговой оценкой студента в вузе.** Категории «отлично/хорошо/удовлетворительно/не сдал» применяются только к конкретной оценке по дисциплине и модулю.

В демонстрации оценки вымышлены; реальные оценки студентов не используются.

## Связь с L3

`analytics_coordinator` вызывает `rating_calc`; `analytics_repo` обеспечивает чтение оценок и сохранение результатов. Этот прототип реализует только **вычислительную часть `rating_calc`**. gRPC, PostgreSQL, репозиторий и сервисы риска/уведомлений остаются за границами выбранного компонента и не имитируются вымышленными реализациями.
